# Input Component

Input component for text field inputs.
Supports sizes (`sm`, `default`, `lg`) and variants (`default`, `error`).

## Subcomponents & Utilities

### `InputProps`

Props for the Input component.

## Usage Example

```tsx
import { Input } from "@wtasnorg/ui";

function Example() {
  return <Input type="text" placeholder="Enter your name..." />;
}
```
